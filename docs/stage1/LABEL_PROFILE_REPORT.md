# 阶段1：标签数值画像（首轮抽样）

> 输入：`data/processed/stage1_inventory.json`<br>
> 产物：`data/processed/stage1_label_profiles.json`<br>
> 方法：每个表最多读取前 50,000 条记录；该结果用于发现问题，不等同于全量标签审批。

## 主要发现

- 共得到 86 个表/工作表的标签画像。
- 在含 `fitness` 且存在其他数值标签的记录中，形成 157 组可计算的 Spearman 对照；其中 113 组的绝对相关系数为 1，说明大量 `fitness` 很可能是原始标签的单调变换或直接副本。
- 相关方向并不统一：157 组中 94 组为正、63 组为负。这直接支持新方案的文件级方向注册，禁止跨文件盲目拼接原始标签。
- 数据集 11 同时包含 SPR KD、解离速率和 Cell Display EC50；不同 `*_ec50.csv` / `*_spr.csv` 的 `fitness` 对应关系不同，必须按文件和 assay 分开注册，不能仅因同一研究来源合并。
- `AbRank_dataset.csv` 的首 50,000 行中，`IC50 [ug/mL]` 有 21,806 个带比较符的截断值，`Aff_op` 有 21,812 个；这些值不能被静默转成普通浮点数或构造强排序对。
- 两份重复 ANDD 工作簿各发现 2 个带比较符的 `Affinity_Kd(M)`；正式使用时只保留一个物理副本，并按结构 ID 去重。
- 两个 Tsuruta 二分类集的 `fitness` 以及 Kirby binary 数据均只有 0/1 两个唯一值，确认只能作为分类辅助监督。

## 决策

1. `fitness` 可以优先作为“建议主标签”，但只有在逐文件核验其与原始指标的变换关系后才批准。
2. 原始 KD/IC50/EC50 通常是越低越好，而负对数标签通常越高越好；具体方向仍以注册表审批为准。
3. 带 `<`、`>`、`<=`、`>=` 的值保留截断标记，不在当前脚本中擅自取阈值数值。
4. 数据集 11 按 assay 文件分别建立 comparable group；不把 KD、kdis 与 EC50 当成同一目标。
5. 预测亲和力列继续放在弱标层，二分类列放在辅助层，无标签序列不进入主排序监督。
