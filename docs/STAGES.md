## 目录边界

- `docs/`：设计、审计、阶段报告和训练说明。
- `src/bioos_benchmark/`：可安装的模型与数据管线代码。
- `tests/`：自动化测试。
- `scripts/`：数据处理和复现入口。
- `configs/`：赛事与标签配置。
- `data/`：原始数据，以及按脚本生成且默认不提交 Git 的 `data/processed/`。
- `artifacts/`：模型、预测和实验指标；属于可再生产物，默认不提交 Git。
- `visuals/`：阶段 0 架构图等静态图片。
